## 🔑 必背快捷键（五键走天下）

| 快捷键 | 功能 | 备注 |
|--------|------|------|
| `G` | 移动（Grab） | 后跟 `X`/`Y`/`Z` 锁轴；后跟数字精确移动 |
| `R` | 旋转（Rotate） | 后跟轴锁轴、数字精确角度 |
| `S` | 缩放（Scale） | 后跟轴/数字 |
| `Shift+A` | 添加物体 | 菜单：网格 → UV球/圆柱/立方体 |
| `Shift+D` | 复制物体 | 复制后自动选中，接着移动 |

  - 🎨 材质属性（小球图标）
- **模式（Mode）**：选中**骨架**才有"姿态模式"；选中**网格**没有 —— **选中什么决定有什么模式**

## 📦 第 1-9 课：基本体拼装人体

### 视角操作
- 鼠标**中键拖动** = 旋转视角
- **滚轮** = 缩放
- `Shift` + 中键拖动 = 平移

### 人体拼装结果（坐标参考）
| 部位 | 物体 | 位置 (X, Y, Z) |
|------|------|----------------|
| 头 | 球体（UV球） | (0, 0, 1.5) |
| 身体 | 立方体 | (0, 0, 0) |
| 左臂 | 柱体（绕X转90°横着） | (-0.9, 0, 0.9) |
| 右臂 | 柱体（复制 + 绕Z转180°镜像） | (0.9, 0, 0.9) |
| 左腿 | 柱体 | (-0.35, 0, -0.7) |
| 右腿 | 柱体 | (0.35, 0, -0.7) |

### 关键技巧
- **对称复制**：`Shift+D` 后沿 X 移动 `距离×2`（左 -0.9 → 右 0.9 要移 +1.8）
- **镜像翻转**：复制后 `R` + `Z` + `180` 让对称物体方向一致
- **物体长轴方向**：圆柱默认沿 Z 竖着，要横着就绕 X 或 Y 转 90°（**不是绕 Z！**）

### ⚠️ 踩过的坑
- 复制时可能误删选中物体（`X` 键是删除）—— 用 `Ctrl+Z` 撤销
- 移动时把 Y 轴当 X 轴 → 部件跑到前后方向 —— 锁轴 `G→X` 就不会歪

## 🎨 第 10 课：材质上色

### 操作流程
1. 选中物体 → 属性面板点**材质图标**（小球）→ 点 **New（新建）**
2. 改 **Base Color（基础色）** 色块选颜色

### 关键概念
- **材质预览模式**才能看到颜色：`Z` 键弹出圆盘 → 选"材质预览"（彩色球图标）
  - 实体（Solid）模式看不到颜色，这是"上色没变"的常见原因
- **共享材质**：多个物体用同一个材质 → 改一次全部变（四肢共用肤色）
- 常用参数：
  - **Base Color**：基础色
  - **Metallic**：金属度（0-1）
  - **Roughness**：粗糙度（越大越哑光，越小越反光）

### 我的小人配色
- 身体：蓝色 (0.014, 0.014, 0.8)
- 头 + 四肢：肤色 (0.8, 0.466, 0.031)

## 🦴 第 12 课：骨骼 + 摆姿势（重点！）

### 概念
- **骨骼（Armature）** = 看不见的骨头
- **网格** = 肉
- 绑定后：**动骨骼 → 肉跟着动**

### 搭骨架
1. `Shift+A` → 骨架 → 单根骨骼
2. 选中骨架 → `Tab` 进**编辑模式** → `E` 挤出新骨头
3. 骨头顺序：脊柱 → 头 / 双臂 / 双腿（全部挂在脊柱下）

我的骨架（6 根）：
```
脊柱 (0,0,0) → (0,0,0.8)
头   (0,0,0.8) → (0,0,1.7)
左臂 (0,0,0.8) → (-0.9,0,0.8)
右臂 (0,0,0.8) → (0.9,0,0.8)
左腿 (0,0,0) → (-0.35,0,-0.7)
右腿 (0,0,0) → (0.35,0,-0.7)
```

### 绑定（Parent）
1. 选中网格物体 + 骨架（**最后选骨架，骨架是"父"**）
2. `Ctrl+P` → 选 **骨骼（Bone）**
3. **保持偏移（Keep Offset）** —— 物体才不会跳位！

### ⚠️ 踩过的坑（重要！）
1. **"骨骼"选项不出现**：活动对象必须是骨架（最后选中的是骨架），否则菜单只有"物体"
2. **报"无活动骨骼"**：需要在**姿态模式**下选中一根具体骨头再 `Ctrl+P`
3. **绑定后位置乱跳（Y 轴偏移）**：必须用"保持变换/保持偏移"方式绑定
4. **绑定后手"朝前/方向不对"**：物体的**长轴和骨骼方向没对齐**
   - 骨骼方向 = 骨头长度方向
   - 圆柱长轴 = 局部 Z 轴
   - 修法：把圆柱绕自身轴旋转，让长轴与骨骼方向平行

### 摆姿势
1. 选中骨架 → `Ctrl+Tab` 进**姿态模式**（骨架变蓝）
2. 点选一根骨头 → `R` 旋转 → 部件跟着动
3. 我的成果：双手举起（左臂四元数 [0.97,0.07,0.04,0.22]，右臂 [0.93,0.11,0.07,-0.35]）

### 模式速查
| 选中的物体 | 可用的模式 |
|-----------|-----------|
| 骨架 | 物体 / 编辑 / **姿态** / 权重绘制 |
| 网格 | 物体 / 编辑 / 雕刻 / 顶点绘制（**无姿态**） |

## 💡 第 13 课：灯光（进行中）

### 4 种灯光
| 类型 | 像什么 | 特点 |
|------|--------|------|
| 点光 Point | 灯泡 | 向四周发光 |
| **面光 Area** | 摄影棚柔光灯 | 柔和，人像常用（我现在用的） |
| 聚光 Spot | 舞台灯 | 有方向锥形光束 |
| 日光 Sun | 太阳 | 平行光，全局照亮 |

### 三点布光法
1. **主光 Key**：最强，前方偏侧
2. **辅光 Fill**：补阴影，较弱，另一侧
3. **轮廓光 Rim**：背后打光，勾轮廓

### 操作
- 大纲视图点 Light → 属性面板"数据"（灯光属性）→ 类型 / 能量 / 颜色
- 我的三点布光：
  - **主光**：面光 AREA，能量 1000，位置 (2.46, -3.67, 1.12)
  - **辅光**：面光 AREA，能量 300，位置 (3.5, 2.0, 1.0)
  - **轮廓光**：面光 AREA，能量 500，位置 (0, -5, 2)，绕X转90° 照向小人

## 🎬 第 14 课：动画（关键帧）

### 核心概念
- **关键帧（Keyframe）**：告诉 Blender 某个时刻物体的状态（位置/旋转/缩放）
- Blender 自动补出两个关键帧之间的**过渡帧**（插值）
- 类比：画动画片时只画关键张，中间过渡由软件生成

### 制作流程（以"立正→举手"为例）
1. 选中骨架 → `Ctrl+Tab` 进**姿态模式**
2. **第 0 帧**：骨架立正 → `A` 全选骨头 → `I` → 选"旋转（Rotation）"
3. **第 30 帧**：点底部时间轴数字 30 → 抬双臂（`R` 旋转）→ `A` 全选 → `I` → 旋转
4. 按**空格**播放 → 小人从立正到举手，循环动画

### 动画常用操作
| 操作 | 方法 |
|------|------|
| 播放/暂停 | 空格 或 ▶ 按钮 |
| 回到开头 | `Shift + ←` |
| 跳转帧 | 点击时间轴或 ← → |
| 看曲线 | 动画编辑器（Graph Editor） |

### ⚠️ 踩过的坑
- **按 `I` 没弹菜单**：Mac 上中文输入法会吃掉字母键 → 切英文输入法，或用菜单（骨架→插入关键帧→旋转）
- 插入关键帧后要确认**真的在选中的骨骼上**（姿态模式下先 `A` 全选）

### 我的动画数据
- 帧 0：双臂立正 [1,0,0,0]
- 帧 15（过渡）：左臂半抬起 [0.73, 0.62, ...]
- 帧 30：双臂完全举起 [0.7, ±0.7, 0, 0]

## 📝 学习心得

1. **先子后父**：绑定顺序 = 先选子（网格），最后选父（骨架）
2. **长轴对齐**：绑定后方向怪 = 检查部件长轴 vs 骨骼方向
3. **选中决定模式**：想要什么模式，先选中对应类型的物体
4. **Ctrl+Z 是救命键**：做错了随时撤销
5. **保持偏移**：绑定/复制时选"保持偏移/变换"，位置不乱

## ✏️ 第 15 课：编辑模式建模（杯子）

### 概念
- **物体模式**：把物体当整体移动/旋转/缩放
- **编辑模式**：钻进物体内部，改点、线、面（`Tab` 切换）

### 编辑模式三选模式
| 快捷键 | 选择 |
|--------|------|
| `1` | 顶点（点） |
| `2` | 边（线） |
| `3` | 面 |

### 核心操作
| 操作 | 快捷键 | 用途 |
|------|--------|------|
| **挤出** | `E` | 选中面/边/点，沿法线"长"出新形状（建模灵魂） |
| **环切** | `Ctrl+R` | 给表面画环线，加细节（滚轮可加多条） |
| **填充** | `F` | 选中边圈成面（封口/补洞） |
| **循环选择** | `Alt+左键` | 一次选中整圈边 |

### 杯子制作标准流程
1. `Shift+A` → 网格 → 圆柱体
2. `Tab` 进编辑模式 → `3` 面选择 → 点顶面
3. `E` 向上拉（挤出杯壁）→ 左键确认 → 再 `E` 拉一次
4. 点最顶面 → `X` → 删除面（杯口开口）
5. 完成！一个标准马克杯

### ⚠️ 踩过的坑
- **挤出没反应**：顶面没选中（要橙色高亮）；或中文输入法吃了 `E` 键
- **挤出后顶点数不变** = 挤出没确认（按了右键取消）
- **物体上下半显示不一致（上边下面）**：多次操作叠加导致几何体混乱 → 删掉重做最干净
- 编辑模式 `X` 是删**面/点/边**；物体模式 `X` 是删**整个物体** —— 别搞混

## ⚔️ 第 15 课补充：做剑练习

### 剑的制作流程
1. `Shift+A` → 立方体 → 剑胚
2. 压扁：`S` → `Z` → `0.2`（剑身扁）
3. 拉长：`S` → `X` → `4`（剑形）
4. 编辑模式 → `1` 顶点 → `B` 框选右端 4 点
5. **合并成尖**：`S` → `X` → `0`（4点缩到一点 = 剑尖）
   - ⚠️ 关键：直接拉顶点不会变尖，要"合并/缩放归零"成一点
6. 倒角：`2` 边模式 → `A` 全选 → `Ctrl+B` 削出斜面
7. 加剑柄：`Shift+A` → 圆柱 → 缩小 → 移到剑端
8. 上色：剑身 Metallic=1（金属），剑柄棕色/黑色

### ⚠️ 踩过的坑
- **"拉尖"不变尖**：4 个顶点在同一平面，直接推不变尖 —— 要 `S→X→0` 合并成一点
- **选中了不该选的顶点**：框选 `B` 框大了 → `A` 取消重框小一点
- **剑变圆**：倒角段数/宽度太大 → `Ctrl+Z` 重来，少拉点

## 🧙 第 16 课：修改器（Modifiers）

### 概念
- **修改器** = 挂在物体上的"效果器"，不改原始模型，实时加效果
- 随时可删，模型还原（最大的好处）

### 三大修改器
| 修改器 | 中文名 | 效果 | 关键设置 |
|--------|--------|------|---------|
| Array | 阵列 | 复制 N 份排成排/圈 | Count 数量 |
| Mirror | 镜像 | 只做半边，另一半自动对称 | 沿 X/Y/Z 轴 |
| Subdivision Surface | 表面细分 | 让模型变圆滑 | Levels Viewport 视图层级 |

### 操作位置
- 右侧属性面板 → **修改器图标（扳手🔧）** → 添加修改器 → 选类型

### 配套技巧
- **`Ctrl+J` 合并**：把多个物体"焊"成一个，之后修改器作用于整体
  - ⚠️ 修改器只作用于一个物体 —— 想复制"整把剑"要先 `Ctrl+J` 合并剑身+剑柄
- 细分层级 1-2 就够，3 会卡

### ⚠️ 踩过的坑
- **只复制了剑柄没复制剑身**：修改器只作用于当前选中的单个物体，没合并
- 细分会让棱角消失（剑变圆）—— 不喜欢就删修改器还原

## 🌀 第 17 课：曲线建模（Curve）

### 概念
- **曲线** = 可编辑的"线"，本身不是实体，但能变粗（管道）或当路径
- 两种基础曲线：贝塞尔曲线（可弯线）、圆环（环形）

### 曲线变管道（给线加厚度）
1. `Shift+A` → 曲线 → 贝塞尔曲线
2. 选中曲线 → 属性面板 → **曲线数据属性** → **几何（Geometry）** → **倒角（Bevel）** → **深度（Depth）= 0.1**
3. 曲线变成管道/绳子

### 编辑曲线形状
- `Tab` 进编辑模式 → 曲线出现**控制点** + **切线手柄**
- 移动**控制点**（`G`）：曲线跟着弯
- 移动**手柄**：控制点不动，弯曲弧度变化

### 曲线做路径（路径动画）
1. 选中物体 + 曲线（最后选曲线）
2. `Ctrl+P` → **曲线路径 / 跟随路径（Follow Path）**
3. **`Alt+G`**（清空位置）+ **`Alt+R`**（清空旋转）→ 物体对齐到路径起点
4. 空格播放 → 物体沿曲线运动

### ⚠️ 踩过的坑
- 物体没"跳"到曲线起点：`Alt+G` / `Alt+R` 清空变换对齐
- 中文界面"跟随路径"就是 Follow Path（翻译不同，选对了）

## 🖼️ 第 18 课：UV 贴图

### 概念
- **UV** = 把 3D 表面"展开"成 2D 平面（像拆开纸盒摊平）
- **贴图** = 把图片贴到展开的平面上

### 贴图流程
1. 选中物体 → 材质面板 → New → **基础色（Base Color）** → 点**小圆点** → 选"图像纹理（Image Texture）"
2. 点"新建（New）"建图像，或点"打开（Open）"用已有图片
3. 切到**材质预览模式**（Z → 材质预览）看效果

### ⚠️ 踩过的坑（重要！）
- **贴图显示纯黑**：新建图像时类型选了"空白（Blank）"→ 新建弹窗里类型选 **"彩色格子（UV Grid）"** 才有图案
- 黑白棋盘/彩色格子是测试图案，用来检查贴图是否正确

### UV 编辑器
- 视口边缘右键 → 垂直分割 → 右侧编辑器类型菜单 → 选"UV 编辑器"
- 左边 3D 视口选面，右边 UV 编辑器看"摊开的样子"，两边联动

## 🗿 第 19 课：雕刻入门

### 概念
- **雕刻** = 像捏泥巴一样推拉模型表面，做有机形状（头像/怪兽/地形）
- 用笔刷直接刷，比编辑模式（点线面）更直觉

### 雕刻准备（关键！）
- 需要"足够多面"的模型才能雕刻
- **体素重塑（Remesh）**：雕刻前用，把网格变均匀细腻（Voxel Size 越小越细）
- 或者：细分修改器应用后雕刻

### 常用笔刷
| 笔刷 | 效果 |
|------|------|
| 抓起 Grab | 拖拽拉长（耳朵/鼻子/角） |
| 膨胀 Inflate | 鼓起（鼓包/肚子） |
| 捏合 Pinch | 收拢（棱/角） |
| 抹平 Flatten | 压平 |
| 平滑 Smooth | 柔化去毛刺 |

### 雕刻三要素（刷不动时检查）
1. **笔刷强度（Strength）**：调到 0.8-1.0
2. **笔刷大小**：按住 `F` 拖动调
3. **按住左键刷**（不是点一下）

### ⚠️ 踩过的坑
- **强度拉满变化还是小**：网格面太少 → 体素重塑/细分应用
- 找不到"重塑网格"：藏在雕刻模式右侧面板，位置不固定，概念记住即可

## 🌊 第 20 课：物理模拟

### 概念
物理模拟 = 让 Blender 自己算运动，不用手动画关键帧

### 刚体（Rigid Body）—— 硬物体碰撞
1. 属性面板 → **物理属性图标**（圆形带箭头球，在材质图标附近）→ 刚体
2. **主动（Active）**：会受重力下落（球）
3. **被动（Passive）**：不动（地面）
4. 空格播放 → 球掉下来砸地面

### 布料（Cloth）—— 软布飘动
1. 加平面 → 属性面板 → 物理属性 → **布料（Cloth）**
2. **要碰撞的物体必须加"碰撞（Collision）"属性**（否则穿透）
3. 空格播放 → 布飘落

### ⚠️ 布料硬邦邦的终极原因（重点！）
- **修改器顺序错误**：布料修改器如果在细分**前面**，布料用原始 4 顶点平面 → 硬得像钢板
- **正确做法**：先给平面加细分 → **应用（Apply）细分**（变成真实多面网格）→ 再加布料修改器
- 布料柔软参数：质量 Mass（越小越轻）、空气阻力 Air Damping（越大飘得慢）、弯曲刚度 Bending（越小越软）、质量 Quality（越高越细腻）

## 🌧️ 第 21 课：粒子系统

### 概念
粒子 = 让物体发射大量小物体（雨/雪/花瓣/烟花）

### 基本流程（下雨）
1. `Shift+A` → 平面（发射器）→ 放大
2. 属性面板 → **粒子属性图标**（三个小点）→ 新建
3. **发射 Emission**：数量 Number、寿命 Lifetime
4. 空格播放 → 粒子受重力下落

### 粒子变物体（掉真实物体）
1. 建一个"模板"物体（小球/花瓣），缩小放旁边
2. 选中发射器 → 粒子属性 → **渲染 Render** → 类型改 **"物体（Object）"**
3. 选 **实例对象（Instance Object）** = 你建的模板
4. 播放 → 掉下来的全是那个物体

### 用途扩展
- 下雨/下雪 = 小球/小片 + 重力
- 花瓣雨 = 扁椭圆 + 旋转
- 烟花 = 粒子 + 发光材质

## 第 22 课：世界环境（天空/雾/背景）

**目标**：让渲染背景不再是纯黑/纯灰，而是有天空、有氛围。

### 22.1 概念：世界（World）是什么？

Blender 里"背景"不是画布，而是一个叫**世界（World）**的东西 —— 它可以有颜色、有天空纹理、有雾。所有没被灯光照到的背景，都由世界决定。

### 22.2 给世界换颜色

1. 属性面板 → 找**世界属性图标**（一个**小地球🌍**，在材质图标附近）
2. 找到 **表面（Surface）→ 颜色（Color）** → 点色块选颜色
   - 比如选浅蓝色，背景就变浅蓝

### 22.3 用天空纹理（更真实）

1. 世界属性 → 表面 → 点**颜色右边的小圆点** → 选 **"天空纹理（Sky Texture）"**
2. 背景变成**渐变天空**（顶部深蓝、地平线亮）
3. 下方有 **"类型（Type）"** 下拉 → 选 **"带雾的地平线（Hosek/Skylight）"** → 天空更真实

### 22.4 加雾（体积散射，进阶）

1. 世界属性 → 表面 → 小圆点 → 选 **"体积散射（Volume Scatter）"**
2. 把 **密度（Density）** 调到 **0.01~0.05**（很小的值就有雾感）
3. 切到**渲染预览**（Z → 渲染）看雾效（Eevee 需要开启辉光/体积）

### 常见问题
- **背景还是黑的**：检查是否在"渲染模式"看效果（材质预览也能看世界色）；检查世界表面是否设置了颜色
- **雾看不到**：Eevee 引擎的体积渲染默认较弱，效果在 Cycles 下更明显

### 快捷键备忘
- `Z` → 渲染预览：看世界/雾效

## 第 23 课：渲染进阶（Cycles / 景深 / 抗锯齿）

**目标**：从"Eevee 快图"升级到"Cycles 照片级渲染"，学会景深让画面更专业。

### 23.1 概念：Eevee vs Cycles

| 引擎 | 特点 | 适合 |
|------|------|------|
| **Eevee** | 快（实时），效果近似 | 预览、游戏、快速出图 |
| **Cycles** | 慢但真实（光线追踪） | 照片级渲染、作品展示 |

### 23.2 切换 Cycles

1. 属性面板 → **渲染属性图标**（**小相机🎥**）
2. 顶部 **渲染引擎（Render Engine）** → 从 Eevee 改成 **Cycles**
3. 首次渲染会变慢（Cycles 逐光线计算）—— 正常
4. 下方 **采样（Sampling）** → **渲染采样（Render）** 调 **128**（越高越细腻越慢）

### 23.3 景深（背景虚化，专业感神器）

1. 渲染属性 → 往下找 **景深（Depth of Field）**
2. 点"启用"，**焦点物体（Focus Object）** 选你场景的主角（比如小人）
3. 把 **光圈（Aperture）→ 大小（Size）** 调小（比如 0.5）
   - 数值越小，虚化越强
4. 渲染看看：焦点物体清晰，前后背景虚化 —— 像单反照片！

### 23.4 抗锯齿（边缘平滑）

- Cycles 自带抗锯齿，一般不用管
- Eevee 下：渲染属性 → **胶片（Film）→ 抗锯齿（Anti-Aliasing）** 默认开启

### 常见问题
- **Cycles 太慢**：降低采样（64）、减少灯光数量、关掉焦散（Caustics）
- **画面很多噪点（颗粒）**：提高采样，或开启**降噪（Denoising）**（渲染属性 → 性能 → 降噪）
- **景深没效果**：确认焦点物体选对、光圈数值够小

### 快捷键备忘
- `F12`：渲染
- 渲染属性图标 = 相机图标

## 第 24 课：动画进阶（走路循环）

**目标**：让之前的小人走出"循环走路"动画 —— 进阶关键帧的巅峰应用。

### 24.1 概念：循环动画

走路动画是"**循环（Loop）**"的：第 0 帧和第 40 帧姿势一样（一只脚在前），中间走完一步。循环播放就无限走路。

### 24.2 准备

1. 打开之前做的小人场景（有骨架的那个）
2. 选中骨架 → `Ctrl+Tab` 进姿态模式

### 24.3 走路四关键姿势（帧 0 / 10 / 20 / 30）

**帧 0：起步**（左脚在前、左臂在后）
- 左腿骨头：`R` → `X` → 前抬 20°
- 右腿骨头：`R` → `X` → 后抬 20°
- 左臂：后摆 20°；右臂：前摆 20°
- `A` 全选 → `I` → 旋转（记录）

**帧 10：中间**（腿到中间、身体略低）
- 双腿回到基本垂直，身体略下沉（脊柱微降）
- `A` 全选 → `I` → 旋转 + 位置

**帧 20：迈步**（左右腿对调）
- 左腿后抬 20°、右腿前抬 20°（和帧 0 相反）
- 手臂也对调
- `A` 全选 → `I` → 旋转

**帧 30：回中**
- 和帧 10 类似（身体微沉）
- `A` 全选 → `I` → 旋转

**帧 40 = 帧 0**（循环闭合）
- 复制帧 0 的姿势：点时间轴第 40 帧 → `A` 全选 → 右键 → "粘贴姿势"（或直接重摆）

### 24.4 循环播放

- 空格播放 → 小人连续走路
- 想让循环无缝：确认第 40 帧和 0 帧姿势完全一致

### 常见问题
- **走路像"滑步"**：身体（脊柱）也要做上下起伏（帧 10 和 30 略低）—— 走路是全身运动
- **动作太僵硬**：加中间帧（帧 5/15/25）做过渡细节
- **粘不上循环**：首尾帧姿势必须完全一样

### 快捷键备忘
- 姿态模式 `Ctrl+Tab`、`I` 插关键帧、`A` 全选骨头

## 第 25 课：综合大作品（把所学全用上）

**目标**：做一个小场景 —— "小怪兽在桌面上，桌上放着杯子和剑，粒子在下雨，用三点布光和景深渲染"。

### 25.1 规划场景（先想再动手）

```
场景：森林小屋桌面一角
├─ 地面/桌面（立方体压扁）
├─ 小人或小怪兽（第 19 课雕刻的怪兽）
├─ 杯子（第 15 课做的）
├─ 剑（第 15 课做的）
├─ 灯光（三点布光，第 13 课）
├─ 粒子雨（第 21 课）
└─ 世界环境（第 22 课天空）
```

### 25.2 组合步骤

1. **合并进一个场景**：把所有物体 `Ctrl+C` / `Ctrl+V` 或打开文件合并（`File → Append` 追加物体）
2. **摆放**：桌面放大压扁在下方；杯子、剑、怪兽放桌上，调整大小位置（`G`/`S`/`R`）
3. **打光**：按第 13 课做三点布光（主光/辅光/轮廓光）
4. **世界**：按第 22 课加天空纹理
5. **粒子**：加一个平面发射器在场景上方，粒子设成小球/雨滴（第 21 课）
6. **相机**：`Numpad 0` 取景，把怪兽放在画面主体位置
7. **渲染**：切 Cycles（第 23 课）→ 开景深对焦怪兽 → 采样 128 → `F12` 渲染
8. **保存**：`Ctrl+S` + 渲染图 `Alt+S` 存 PNG

### 25.3 出图小技巧

- 渲染前把所有物体选中 → `Ctrl+A` → "全部变换"应用（避免缩放导致的渲染异常）
- 粒子太多会卡：先渲染测试（低采样 32），满意了再开高采样
- 背景黑/灰：确认世界有颜色或天空

### 验收标准
渲染出一张图，包含：**怪兽 + 杯子 + 剑 + 雨 + 打光 + 景深虚化背景** —— 完成即毕业！
