## 🎯 学习路线

- **Blender**：先学基础五键（G/R/S/Shift+A/Shift+D）→ 基本体拼装 → 材质上色 → 骨骼动画 → 灯光渲染 → 编辑模式建模 → 修改器 → 曲线 → UV 贴图 → 雕刻 → 物理模拟 → 粒子系统
- **Godot**：界面入门 → 2D 角色移动 → 碰撞小游戏 → GDScript 语法 → 3D 导入 Blender 模型 → 角色控制 → UI 分数 → 导出游戏

## 💡 组合玩法

**Blender 建模 → Godot 做游戏**：Blender 里建模导出的 .glb 文件可直接导入 Godot 当游戏资产 —— 独立游戏开发者的经典工作流。
